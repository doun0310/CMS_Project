# Admin Wireframes

기준일: 2026-07-23

## 1. 목적

본 문서는 관리자 화면의 초기 와이어프레임 구성을 텍스트 기반으로 정의한다.

## 2. 공통 레이아웃

```text
+--------------------------------------------------------------+
| Header: Logo | Search | User Menu                           |
+--------------------+-----------------------------------------+
| Sidebar            | Main Content                           |
| - Dashboard        |                                         |
| - Requests         |                                         |
| - Approvals        |                                         |
| - Print Jobs       |                                         |
| - Printers         |                                         |
| - Policies         |                                         |
| - Templates        |                                         |
| - Audit Logs       |                                         |
+--------------------+-----------------------------------------+
```

설계 포인트:

- 좌측 고정 사이드바
- 상단 공통 검색/계정 영역
- 메인 영역은 목록 + 상세 구조 우선

## 11. 우선 구현 화면

1. 승인 대기 목록
2. 승인 상세 처리
3. 요청 목록/상세
4. 출력 작업 목록
5. 프린터 관리

## 12. UX 메모

- 상태는 텍스트와 색을 함께 사용
- 실패/반려/민감 건은 한눈에 구분되게 표시
- 목록에서 상세 열람 동선이 짧아야 함
- 관리자 화면은 데스크톱 해상도 기준 우선 설계
