# Testing Strategy

기준일: 2026-07-23

## 1. 목적

본 문서는 CMS Printer Application의 테스트 전략을 정의한다.

## 2. 테스트 레벨

### Unit Test

대상:

- 서비스 로직
- 정책 판단 로직
- 상태 전이 로직

도구:

- Jest

### Integration Test

대상:

- Express 라우트
- 컨트롤러 + 서비스 흐름
- DB 연동 리포지토리

도구:

- Jest
- Supertest

### Manual Test

대상:

- Agent 연동
- 실제 프린터 환경
- 관리자 운영 시나리오

도구:

- Postman
- API 테스트 시나리오 문서

## 3. 현재 상태

- 헬스체크 테스트 골격 작성 완료
- Swagger UI 응답 테스트 골격 작성 완료
- Postman 컬렉션 초안 작성 완료

## 4. 우선 추가할 테스트

1. 인쇄 요청 생성 성공/실패
2. 승인/반려 처리
3. 출력 큐 적재
4. Agent status update
5. 관리자 CRUD
6. `404/403/400` 에러 응답 검증

## 5. 권장 원칙

- 서비스 로직은 가능한 한 순수 함수 또는 분리된 단위로 테스트
- DB 의존 테스트는 별도 테스트 DB 사용
- 외부 프린터 의존 테스트는 수동 테스트로 분리
- 실패 케이스 테스트를 성공 케이스만큼 중요하게 다룸

## 6. 향후 보완

- 테스트 DB 초기화 스크립트
- CI 환경 테스트 실행
- 커버리지 기준 정의
- 통합 테스트 fixture 표준화
