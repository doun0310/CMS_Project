# CMS Printer Application PM Summary

기준일: 2026-07-23

## 1. 프로젝트 목적

사내 CMS와 연동하여 인쇄 요청, 승인, 출력, 재인쇄, 감사 로그를 통합 관리하는 프린터 애플리케이션을 구축한다.

## 2. 기대 효과

- 출력 요청 표준화
- 무분별한 인쇄 방지
- 승인 책임 추적 가능
- 재인쇄 통제 가능
- 부서별 프린터 운영 통합

## 3. 현재 상태

현재까지 초기 백엔드 및 DB 구조가 준비되어 있다.

- DB 스키마 초안 완료
- 초기 시드 데이터 완료
- 핵심 API 골격 구성 완료
- 승인/출력/에이전트 흐름 기본 구현 완료
- 프린터/정책/템플릿 관리 API 기본 구조 완료
- 감사 로그 구조 반영 완료

## 4. 남은 핵심 과제

- 실행 환경 검증
- 실제 인증 방식 적용
- 관리자 조회 기능 보강
- 테스트 코드 추가
- 배포 준비

- Agent 운영 위치 및 배포 방식 미확정
- 승인 정책 복잡도 증가 가능성

## 7. 의사결정 필요 항목

- JWT와 사내 SSO 중 어떤 인증 방식을 쓸지
