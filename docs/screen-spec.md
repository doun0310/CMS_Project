# CMS Printer Application Screen Specification

기준일: 2026-07-23

## 1. 목적

본 문서는 CMS Printer Application의 주요 화면 구성을 정의한다.

대상 사용자:

- 실무자
- 중간 관리자
- 매니저
- 시스템 관리자

## 2. 화면 목록

### 공통

- 로그인 화면 또는 SSO 진입 화면
- 대시보드

### 실무자

- 인쇄 요청 등록 화면
- 본인 요청 목록 화면
- 요청 상세 화면
- 재인쇄 요청 화면

### 중간 관리자

- 승인 대기 목록 화면
- 승인 상세/처리 화면
- 팀 요청 이력 화면

### 매니저

- 부서 승인 대기 목록 화면
- 예외 승인 화면
- 부서 출력 현황 화면

### 시스템 관리자

- 프린터 관리 화면
- 승인 정책 관리 화면
- 템플릿 관리 화면
- 감사 로그 조회 화면

## 3. 화면별 상세

### 3.1 인쇄 요청 등록 화면

목적:
- 실무자가 문서 인쇄를 요청한다.

주요 입력 항목:

- 문서 유형
- 원본 문서 ID
- 템플릿 선택
- 프린터 선택
- 출력 부수
- 민감 문서 여부
- 긴급 여부
- 요청 사유

주요 동작:

- 요청 등록
- 필수값 검증
- 정책 기반 승인 라우팅

노출 정보:

- 예상 승인자 역할
- 요청 생성 결과

### 3.2 본인 요청 목록 화면

목적:
- 실무자가 본인 요청 상태를 조회한다.

조회 항목:

- 요청번호
- 문서 유형
- 요청일시
- 상태
- 프린터
- 부수
- 재인쇄 여부

필터:

- 상태
- 문서 유형
- 기간

주요 동작:

- 상세 보기
- 재인쇄 요청

### 3.3 요청 상세 화면

목적:
- 요청과 승인/출력 이력을 상세 확인한다.

노출 정보:

- 기본 요청 정보
- 승인 단계
- 승인자
- 승인/반려 사유
- 출력 작업 상태
- 실패 사유
- 감사 로그 요약

### 3.4 승인 대기 목록 화면

목적:
- 승인권자가 처리해야 할 요청을 조회한다.

조회 항목:

- 요청번호
- 요청자
- 부서/팀
- 문서 유형
- 부수
- 민감 여부
- 요청일시

필터:

- 문서 유형
- 민감 여부
- 요청일시

주요 동작:

- 승인
- 반려
- 상세 보기

### 3.5 승인 상세/처리 화면

목적:
- 승인권자가 요청 내용을 검토하고 처리한다.

노출 정보:

- 요청 문서 정보
- 템플릿 정보
- 부수
- 요청 사유
- 재인쇄 여부 및 사유

입력 항목:

- 승인 코멘트
- 반려 사유

주요 동작:

- 승인 처리
- 반려 처리

### 3.6 프린터 관리 화면

목적:
- 시스템 관리자가 프린터를 등록/수정/비활성화한다.

조회 항목:

- 프린터 코드
- 이름
- 유형
- 연결 방식
- IP 주소
- Agent Key
- 조직
- 위치
- 상태

주요 동작:

- 신규 등록
- 수정
- 상태 변경

### 3.7 승인 정책 관리 화면

목적:
- 문서 유형별 승인 규칙을 관리한다.

조회 항목:

- 문서 유형
- 최소 부수 기준
- 재인쇄 승인 필요 여부
- 매니저 승인 필요 여부
- 민감 문서 승인 필요 여부
- 조직
- 상태

주요 동작:

- 정책 등록
- 정책 수정
- 정책 활성/비활성

### 3.8 템플릿 관리 화면

목적:
- 문서 템플릿을 등록하고 버전을 관리한다.

조회 항목:

- 템플릿 코드
- 이름
- 문서 유형
- 버전
- 파일 경로
- 상태
- 생성자

주요 동작:

- 템플릿 등록
- 버전 갱신
- 상태 변경

### 3.9 감사 로그 조회 화면

목적:
- 주요 행위 이력을 감사 목적으로 조회한다.

조회 항목:

- 발생 시각
- 사용자
- 액션 유형
- 대상 유형
- 대상 ID
- 상세 내용

필터:

- 사용자
- 액션 유형
- 대상 유형
- 기간

## 4. 권한 기준

### 실무자

- 인쇄 요청 등록
- 본인 요청 조회
- 재인쇄 요청

### 중간 관리자

- 팀 승인 목록 조회
- 승인/반려 처리
- 팀 이력 조회

### 매니저

- 부서 승인 목록 조회
- 민감/대량 문서 승인
- 부서 현황 조회

### 시스템 관리자

- 프린터/정책/템플릿 관리
- 전체 감사 로그 조회

## 5. UX 고려사항

- 상태값은 색상과 텍스트를 함께 사용
- 반려 사유는 목록에서도 요약 노출
- 민감 문서는 배지로 표시
- 재인쇄 건은 원본 요청과 연결 표시
- 모바일보다는 데스크톱 우선 설계

## 6. 차후 확장 화면

- 통계 대시보드
- 부서별 출력 리포트
- 장애/실패 모니터링 화면
- Agent 상태 모니터링 화면
